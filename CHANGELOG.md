# Changelog

All notable changes to ItchEvi are documented here. The project follows
semantic versioning after its first public release.

## 0.5.0 - release candidate

- Added the failure-aware qualification core and terminal ledger.
- Added CLI and Python API entry points.
- Added seven Draft 2020-12 JSON Schemas.
- Added deterministic TSV-to-JSON normalization.
- Preserved missing numeric evidence as JSON `null`, never zero.
- Added provenance-complete success and failure manifests.
- Added a synthetic end-to-end demo and scaling benchmark.
- Accepted the same wheel under Python 3.11 and 3.12 on one Windows host.

This entry does not assert a public release date. Hosted CI, Docker execution,
final authorship, repository URL, and archival DOI remain release gates.
